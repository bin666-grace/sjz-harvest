# 审查轮次 3 · 实机截图驱动的适配

- 日期：2026-11-18
- 输入：用户提供的 4 张实机截图（`pi/*.jpg`，2712×1220）：
  1. 工作台物品页，左侧列表 + 右侧详情，底部「一键补齐」；
  2. 游戏主界面，底部导航含「特勤处」；
  3. 特勤处总览，四部门卡片（技术中心/工作台/制药台/防具台），显示「空闲中」；
  4. 防具台物品页，同类布局。
- 结论：此前的架构把制造建模成「列表页 → 点击物品 → 独立弹窗」，
  与实机不符；本轮按截图重构补产路径，并修复主界面/交易行误判与恢复逻辑。

## 发现与修复

### R3-01（高）手游制造没有独立弹窗

- 实机：左侧物品列表、右侧详情、底部操作按钮**同屏**。
- 原实现：点击物品后 `awaitState(isStrongCraftDialog)`，等不到「开始制造」弹窗，
  必然 `PAGE_ERROR`；或在列表页因「材料」被判 `CRAFT_DIALOG` 而直接失败。
- 修复：
  - 点击列表行后等待「操作区出现（开始制造 / 一键补齐）」且右侧详情标题
    确认为目标物品；
  - 初始页面为弱 `CRAFT_DIALOG`（列表页）时继续扫描，不再直接报错；
  - 扫描循环里只有“强面板且详情就是目标”才提前操作，避免误造上一件物品。

### R3-02（高）材料不足按钮是「一键补齐」

- 实机：材料数量如 `4/2`、`0/2`，底部按钮显示「一键补齐」；点击会进入补料/
  交易行，涉及真实资产。
- 修复：新增 `craft.fillMaterialsTexts`。检测到即返回 `MISSING_MATERIALS`，
  **v0.1 永不点击**；部门进入冷却，由上层恢复总览。只有出现「开始制造」才点击。

### R3-03（高）右侧详情可能仍是上一件物品

- 风险：点击列表行未命中时，右侧详情仍显示之前选中的物品，底部「开始制造」
  依然存在；若直接点击，会制造错误物品并扣计划。
- 修复：新增 `craft.detailRegion`（基准坐标）。点击后 OCR 只检查该区域，
  目标名必须匹配（精确/包含/阈值相似）；不匹配 → `PAGE_ERROR`，不点击。
- 同时配置 `itemList.viewport` 限定左侧列表，避免右侧标题（也含物品名）
  被当作可点击行。

### R3-04（高）主界面底部「交易行」被误判为拍卖页

- 实机主界面底部导航含「交易行」，原判页只要单个锚点命中就返回 `AUCTION`。
- 修复：`auction.anchorTexts` 至少命中 **2 个** 才判 `AUCTION`
  （真交易行同时有「交易行」「最低价」）。

### R3-05（高）恢复总览盲目按返回可能退出游戏

- 原实现：`recoverToDashboard()` 先发 `back` 再看页面。起始在主界面时，
  两次返回可能直接退出游戏。
- 修复：
  - 先判页再动作；
  - 识别主界面（底部导航 ≥3 个文字命中），点击最靠下的「特勤处」；
  - 无部门标题、又非弹窗/交易行时**不按返回**，直接返回失败让流程停止；
  - 部门详情页有标题时才 `back`。

### R3-06（中）有「制造中」但无计时器会被当成 DONE

- 风险：OCR 漏读计时器时，`doneWhenNoStatus=true` 会回退成 DONE，
  触发错误的收取。
- 修复：新增 `dashboard.craftingKeywords`（制造中/生产中），在计时器之后、
  完成之前判断为 `CRAFTING`。

### R3-07（中）收集按钮在部门详情页右下角，标题半径搜不到

- 实机：操作按钮位于屏幕右下（如「一键补齐」位置）；收取按钮很可能也在附近。
- 修复：总览页仍只在标题半径内找；部门详情/列表页改为**全页查找**
  `collectButtonTexts`。

### R3-08（中）收取后的奖励弹窗会让恢复流程停止

- 风险：收取后游戏可能弹出奖励面板；页面没有部门标题、可能被判 `UNKNOWN`，
  原保护逻辑会直接返回失败，导致每次收取后自动化停止。
- 修复：无部门标题且非制造/拍卖页时，先在全屏找**完全等于**
  `craft.backTexts`（取消/关闭/返回/确定/确认）的元素并点击；找不到才停止。
  只接受完全相等，避免把包含这些词的说明文本误当按钮。

### R3-09（中）dry-run 无法自动导航导致 8 秒超时

- 修复：dry-run 在总览点部门时立即提示“请手动进入部门物品页”，不空等；
  命中目标后记录 `panel/fill` 识别结果并返回，不等待详情切换、不扣计划。
- 文档已注明：验证补产需手动进入目标部门列表。

## 配置变更

| 字段 | 值 | 说明 |
|---|---|---|
| `supportedWidths` | +2712 | 实机截图宽度 |
| `itemList.viewport` | `{0,220,600,860}` | 左侧列表，基准 1920×1080 |
| `craft.detailRegion` | `{600,90,700,220}` | 右侧详情标题 |
| `craft.fillMaterialsTexts` | `["一键补齐"]` | 材料不足标志，不点击 |
| `dashboard.craftingKeywords` | `["制造中","生产中"]` | 无计时器时的制造态 |
| `dashboard.lobbyNavTexts` | 5 个底部导航文字 | 识别游戏主界面 |
| `dashboard.lobbyEntryText` | 特勤处 | 主界面进入总览 |
